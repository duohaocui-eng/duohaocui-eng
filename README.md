## Featured Project

### [Search-and-Verify Research Agent](https://github.com/duohaocui-eng/SearchAndVerify-Research-Agent)

一个可追溯的 Research Agent 公开作品，围绕 **Evidence Loop + Open Research Loop**、OA 全文证据定位与权限隔离展开，并保留可复现的冻结评测与逐条实验结果。

- **Authority isolation**：30 个冻结权限场景中，isolated controller 保持 **0 次 Formal State 污染、30/30 正确升级**
- **OA full-text evidence**：28 个预标正例 passage 的定位由 abstract-only **10/28 提升至 28/28**
- **Independent holdout**：15 个新靶点、60 次真实模型逻辑运行，对比 stepwise / compact 的质量与稳定性

项目仓库包含可离线运行的 demo、tests、evaluation scripts 和公开 evidence，可从 README 继续下钻验证。
